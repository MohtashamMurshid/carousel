# Contributing

Issues and focused pull requests are welcome.

- Open an issue before large work.
- Run `npm test` (and `npm run build` if you touched the UI or export path) before you send a PR.
- Keep the change small. No drive-by refactors, dependency churn, or formatting-only diffs.
- Do not add auth, a backend, or a GitHub mirror.
- Fixture copy and CSS planes stay original. Do not hotlink DashboardStack images.

This is a client-only Vite app. The deck lives in the URL.
